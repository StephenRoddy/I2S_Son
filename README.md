### Sonifying I²S Transport Signals to Detect Transmission Faults. 

This repository contains an example prototype design for the sonification of I2S data. It operates on synthetic I2S signals generated by the script. The approach is intended for use in detecting transmission faults by listening. 
The repo also includes code for the production and analysis of sonification dataset based on this prototype. 

The results of this analysis are discussed in a paper for the forst IEEE Workshop on Sonification for the Internet of Sounds at the 2026 Internet of Sounds Symposium.

The paper is entitled "Sonifying I²S Transport Signals to Detect Transmission Faults".
